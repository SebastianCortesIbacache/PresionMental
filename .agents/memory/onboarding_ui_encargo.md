# 🎨 Encargo: UI Clay para Onboarding (NamePopup)
**Para:** Agente Gráfico (@[conversation:"Grafico"])

Necesitamos transformar la pantalla de ingreso de datos (onboarding) para que tenga EXACTAMENTE el mismo nivel de detalle, texturas de plastilina y decoración que el logo principal del Splash Screen. 

Para lograr esto, en vez de usar CSS básico, construiremos la interfaz usando props 3D de arcilla generados por ti.

### Asset 1: Mascota (El Panda)
- **Archivo:** `assets/interface/onboarding_panda_t1.webp`
- **Dimensiones:** `512x512` (fondo transparente)
- **Descripción:** Mochi (el panda) en estilo 3D Clay. Debe estar en una pose **diferente** a la del splash. Por ejemplo: asomándose desde abajo, saludando alegremente con una mano, o sosteniendo un lápiz de plastilina. Sin textos. Muy suave y táctil.

### Asset 2: Tablero Base (El fondo del formulario)
- **Archivo:** `assets/interface/onboarding_clay_board.webp`
- **Dimensiones:** `800x800` (fondo transparente)
- **Descripción:** Un tablero o placa de plastilina (clay slab) muy redondeado y suave, casi como una nube o un "squircle" irregular. Color blanco crema o pastel muy muy clarito. Debe tener bordes suaves iluminados, sombras que le den mucho volumen 3D, simulando ser la base donde se escribirá. Sin huecos en el centro, debe ser una placa sólida.

### Asset 3: Decoraciones Flotantes (Flores, hojas y estrellas)
- **Archivo:** `assets/interface/onboarding_clay_decorations.webp`
- **Dimensiones:** `800x800` (fondo transparente)
- **Descripción:** Un marco o conjunto de elementos dispersos por los bordes (estrellitas amarillas, pequeñas hojas verdes, margaritas o flores moradas/rosas de plastilina). Igual a los detalles que rodean el logo de "RETO PANDA". El centro debe estar **totalmente vacío** (transparente) para que podamos superponer esta imagen sobre el tablero y el formulario quede en el medio.

---
**Instrucciones para el Agente Gráfico:**
Genera estas 3 imágenes manteniendo la estética "Clay World" (plastilina 3D renderizada, iluminación suave de estudio, texturas táctiles, colores vibrantes pero pasteles) y guárdalas en las rutas especificadas.
